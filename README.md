# DiaGO Desktop — releases

This repository hosts the **installers and release notes** for DiaGO Desktop, the Windows app for
[DiaGO](https://diagoo.vercel.app) — learn software design and draw UML, ER and architecture diagrams.

**Download:** <https://diagoo.vercel.app/desktop> (always the latest stable version), or pick a version under
[Releases](https://github.com/Pushkar236/diagoo-desktop-releases/releases).

- Windows 10 and 11, 64-bit.
- Free. Works offline. Your diagrams are `.diagoo` files on your own computer.
- Each release lists the installer's SHA-256 so you can check the download.

### "Windows protected your PC"

The installer is not code-signed yet, so Windows SmartScreen may warn the first time you run it. Click **More info**,
then **Run anyway**. Only run installers downloaded from this page or diagoo.vercel.app.

### Problems or ideas

Open an [issue](https://github.com/Pushkar236/diagoo-desktop-releases/issues) — please include the version from
**Help ▸ About DiaGO**.

The application's source code is maintained in a separate repository.
